# Code of conduct

This is a joke project. Keep the jokes in the excuses, not aimed at people.

- Be kind to contributors, especially in spelling discussions. Arabizi has no standard, and everyone writes it a little differently.
- No harassment, insults, or personal attacks, in issues, pull requests or anywhere else the project lives.
- No content that breaks the rules in [CONTRIBUTING.md](CONTRIBUTING.md#what-gets-merged).

The maintainer may edit or remove comments, close issues and pull requests, and block people who don't follow this. To report a problem privately, contact the maintainer through their GitHub profile, [github.com/Sahmaoi](https://github.com/Sahmaoi).
